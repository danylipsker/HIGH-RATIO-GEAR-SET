## 2026-10-27: the trailing root fillets were drawn the long way round

Dany's sketch showed a fillet as a 270 degree loop between a flank and the radial line. Cause,
in `GearMath.FilletSeg(mirror: true)` and in gearset.py's `fillet_seg(mirror=True)` alike: the
mirrored fillet segment is reflected across the tooth centre line AND listed backwards (T1 -> T2),
and the two reversals cancel, so the turning sense in the segment's own order is the original
one -- the code flipped it. SolidWorks' `CreateArc` and the DXF `ARC` (always counter-clockwise
from start to end angle) then took the long way: every trailing fillet of every gear a near
full circle, the leading ones right. The sampled polylines (rolling check, STL, the family path's
solids) never used the flag, which is why the numbers and the family-path builds were clean.

Fixed in both languages; measured on the default set with a small harness: all twelve fillet
arcs now sweep 66..88 degrees (before: the trailing six 272..294). `output/*` regenerated with
`build_all.py`; the DXF fillet arcs of the default set all under 90 degrees. Copies in GEARS
GENERATOR updated (`HighRatio\GearMath.cs`, `py/gear_step/high_ratio_core.py`).

Verified on Dany's SolidWorks 2020 (2026-10-27): the fillets blend, the set built.

## 2026-10-27: the flank spline doubled the radial line

Dany's next sketch (a sun or planet root, zoomed): a straight line alongside the lower end of
the flank spline, both from the fillet's end to the base circle. Cause, in both languages: with
a fillet AND a radial line between it and the base circle (external gears with rb > rf), the
flank's first point was still moved down to the fillet's end T1, so the spline ran from T1 up
through the base circle, over the radial line T1 -> rb. Now the flank starts at the base circle
when a radial line precedes it, and at T1 only when the fillet meets the involute itself
(rb <= rf). Checked with a harness over six sets, every gear: no gaps between segments, no
zero-length lines, no repeated or reversing spline points, every flank after a radial line
starting at rb, every fillet arc short, tooth 0 meeting tooth 1. The C# and Python outlines
agree point for point as before.

Verified on Dany's SolidWorks 2020 (2026-10-27): the doubled line at the base circle is gone, the set built.
