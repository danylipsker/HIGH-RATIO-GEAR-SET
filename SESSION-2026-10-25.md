# Session — 2026-10-25 (500-to-1 gear set)

**Branch:** claude/magical-meitner-0e3cfu

## Summary
New, self-contained folder `HIGH-RATIO-GEAR-SET/` (named `500-to-1-gear-set/` when first merged): a parametric generator
(`gearset.py`) for a single-planet 3K / Wolfrom-type compound planetary reducer with
a floating thin ring, plus the SolidWorks macro that builds the parts and assembly.
Default output: exact 1:500, module 1 (`output/ratio-500_m1/`).

## What changed
- `gearset.py`: exact-ratio integer search over (Zs, Zp, Zr1, Zr2, Zf, Zo) with design
  rules (working pressure angle of the profile-shifted ring mesh, thin ring wall,
  tooth differences, undercut), involute geometry for external/internal gears with
  profile shift and backlash, mesh phasing, writers for the design report,
  SolidWorks equations file, JSON, DXF (lines + arcs), SVG/PNG layouts, binary STL,
  and the filled-in VBA macro. Independent kinematic check and a rolling
  tooth-interference check are part of every run.
- `solidworks/BuildGearSet.bas.template`: macro that computes the involutes itself in
  VBA, self-calibrates extrude/offset/arc direction conventions, builds six parts
  with custom properties and equations, and places them in `GearSet.SLDASM`.
- `README.md` in the folder: mechanism, why the requested 16/32/99/100 could not be
  used verbatim, usage recipes, option table, verification and limits.

## Decisions
- Topology: sun → one planet on an idle eccentric carrier → floating thin ring
  (internal + external teeth) → fixed ring + output ring differing by 1–3 teeth on
  the same external toothing (profile shifted). A grounded ring is required for a
  1-DOF mechanism; the user's "99 internal / 100 external" ring is impossible with
  one module (root circles overlap), so Zr2 − Zr1 ≥ 8 is enforced.
- Default 1:500 set: 24 / 20 / 102 / 114 / 152 / 150 (α_w 27.1°, x_o = +1.178,
  OD 165 mm at m = 1), chosen over the sun-16 set (16/18/96/123/167/164, α_w 28.9°)
  for the lower working pressure angle and 2-tooth ring difference.
- Macro untested (no SolidWorks here), same caveat as `STEP_to_SLDPRT_batch.bas`;
  DXF and STL are the no-macro fallbacks.
- The user's local reference folder
  (`...\500-to-1-ultra-compact-gear-ratio-model_files`) was not reachable from the
  cloud session; design follows the published description of that model (planetary +
  "grinder" gears, output reversed).
