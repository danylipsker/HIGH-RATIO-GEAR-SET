## How the ratio arises

All centres are fixed in the carrier frame, so Willis' method applies mesh by mesh:

```
carrier speed      wc = ws * Zs*Zr2 / (Zf*Zr1 + Zs*Zr2)
thin ring speed    wt = wc * (Zr2 - Zf) / Zr2          (rolls inside the fixed ring)
output ring speed  wo = wc * (Zo - Zf) / Zo
ratio              i  = ws / wo = Zo*(Zf*Zr1 + Zs*Zr2) / (Zs*Zr2*(Zo - Zf))
                      = 155*(158*115 + 16*123) / (16*123*(155 - 158)) = -1560695/2952 = -528.690718
```
The fixed ring is required: without a grounded ring the mechanism has two degrees of freedom and the
output ring would not be driven. The output ring differs from the fixed ring by 3 teeth and meshes with the same external teeth of the thin ring, which is why it is profile shifted.
