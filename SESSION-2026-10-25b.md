# Session - 2026-10-25 (add-in)

**Repository:** danylipsker/HIGH-RATIO-GEAR-SET (moved out of fasteners-catalog, PRs #6-#8 there)

## Summary
SolidWorks add-in (C#, 2020+) replacing the macro as the main delivery: dialog with module and
gear ratio text boxes, list of all exact tooth-set solutions (or nearest ratios), overall dimensions
of the picked set, Build writes only the six .SLDPRT and GearSet.SLDASM. Verified end to end on
Dany's SolidWorks 2020: compiles against the real interop, registers, Gear Set tab and dialog work,
default 1:500 set built, zero interferences.

## What changed
- `solidworks/addin/`: AddIn.cs, GearSetForm.cs, GearMath.cs (port of gearset.py), GearBuilder.cs
  (port of the VBA builder to the typed API), GearSetAddin.csproj, install.ps1, icons.
- `solidworks/swcli/GearSetCli`: solve / test-dialog / build from the command line, same code.
- `solidworks/stubs/`: interop stubs + compile_check.sh (Mono) - compile check without SolidWorks.
- install.ps1 hardened after the first install left no HKLM Addins key: re-launch in 64-bit
  PowerShell, per-user HKCU\Software\SolidWorks\Addins entry, registration check at the end.

## Decisions
- Add-in is primary, macro kept as the no-build fallback; both share the same geometry rules.
- The add-in writes nothing but SolidWorks files; design data goes into custom properties and the
  dialog's dimensions panel.
- Solver ranking: working pressure angle, ring tooth difference, undercut, closeness to 16/32/99/100,
  size - identical in Python and C# (cross-checked).

- Mates added by the add-in (GearBuilder.AddMates): Front-Plane coincident, concentric on shaft / pin /
  journal / ring cylinders (faces found by radius + z range through GetBodies3/GetFaces/CylinderParams,
  selected with Select4 mark 1, AddMate5 - the pattern of the fastener add-in), and gear mates
  sun -> carrier / planet / thin ring / output ring with absolute speed ratios.

## Verified on Dany's SolidWorks 2020 (end of session)
- Add-in listed and loaded, dialog, build of the default set, zero interferences, mates added,
  sun drives the whole train.

- Gear-mate direction convention confirmed (Flip = true -> same direction); 10 sun turns -> 7.2 deg
  on the output ring measured by Dany: the 1:500 ratio is verified in motion.
